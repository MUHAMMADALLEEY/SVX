# Sock showcase images

The curated website assets live in `public/images/socks/`. Their semantic filenames match the IDs
in `data/site-content.ts`, while the original WhatsApp exports remain in `public/images/`.

When adding new samples, use a descriptive kebab-case filename, add its metadata to
`sockShowcaseImages`, and confirm that any visible third-party branding is approved for publication.
